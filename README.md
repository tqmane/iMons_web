## iMons for Android とは

Twitter/X の動画保存サイトの**保存ランキング**を閲覧できる、Android 向けの無料アプリです。iOS 版 **iMons**（開発: yyyywaiwai）を Android へ移植したフォーク版で、tqmane が保守しています。

### 主な特長

- 📊 **保存ランキング** — monsnode をはじめとする複数の動画保存サイトのランキングをアプリからチェック
- 🗂️ **10 サイト対応** — 複数のソースをひとつのフィード・検索・ランキングで横断
- 🚫 **広告なしでダウンロード** — 気に入った動画はそのまま端末に保存（ダウンロードキュー・再試行・一括保存・オフライン再生）
- ⭐ **お気に入りとフォルダ** — 保存した動画を整理、スナップショットで一覧を記録
- 🔄 **iOS ⇔ Android データ移行** — iOS 版 iMons との間で JSON / ローカルネットワーク / Google Drive バックアップによりデータを移行
- 🔒 **生体認証ロック** — アプリ起動時のロックに対応
- 🎨 **テーマとアイコン** — 7 種のカラーテーマ・ライト/ダーク・複数のアプリアイコン（一部の外観カスタマイズは [Patreon](https://www.patreon.com/cw/yyyywaiwai) 特典）

### 動作環境

- Android 8.0 以降
- 無料 / アプリ内広告なし / アカウント登録不要

### インストール

1. [最新リリース](https://github.com/tqmane/iMons_web/releases/latest) から APK をダウンロード
2. 端末で「提供元不明のアプリ」のインストールを許可
3. APK を開いてインストール

> ⚠️ 配布は GitHub Releases および公式サイトのみです。Google Play では配布していません。他所で配布されている APK は使用しないでください。

### What is iMons for Android?

A free Android app for browsing the **save rankings** of Twitter/X video-saving sites. It's an Android port of the iOS app **iMons** (created by yyyywaiwai), maintained as a fork by tqmane.

### Highlights

- 📊 **Save rankings** — check rankings from monsnode and other video-saving sites right in the app
- 🗂️ **10 sources** — browse multiple sources through one feed, search, and ranking
- 🚫 **Ad-free downloads** — save videos you like straight to your device (download queue, retry, bulk save, offline playback)
- ⭐ **Favorites & folders** — organize saved videos and capture lists as snapshots
- 🔄 **iOS ⇔ Android data transfer** — move data to and from iOS iMons via JSON, local network, or Google Drive backup
- 🔒 **Biometric lock** — protect the app behind a device lock
- 🎨 **Themes & icons** — 7 color themes, light/dark, and multiple app icons (some appearance customization is a [Patreon](https://www.patreon.com/cw/yyyywaiwai) perk)

### Requirements

- Android 8.0 or later
- Free / no in-app ads / no account required

### Install

1. Download the APK from the [latest release](https://github.com/tqmane/iMons_web/releases/latest)
2. Allow installation from unknown sources on your device
3. Open the APK to install
